Pricing math

SwapLoop is a single-pool x·y=k market maker (Uniswap-V1 style, no router):

getAmountOut(amountIn, rIn, rOut) =
    (amountIn * 997 * rOut) / (rIn * 1000 + amountIn * 997)

The 0.3% fee (3/1000) stays inside the reserves, so it accrues to LP shares rather than to a fee recipient. Initial liquidity mints sqrt(amount0 * amount1) - MINIMUM_LIQUIDITY shares; subsequent adds mint min(amount0 * total/r0, amount1 * total/r1).

removeLiquidity(shares) burns your shares and returns your
proportional slice of BOTH reserves: amountX = shares * reserveX / totalShares

Build & verify

cd botchain-builds/agent-vault
node build5.mjs              # solc 0.8.30 → artifacts/swaploop/*.bin|.abi
node deploy-5-testnet.mjs    # deploy to chain 968 → deployed-testnet-5.json
node demo-txs-5-testnet.mjs  # funding + 6 demo txs
node make-flat-5.mjs         # SPDX-dedupe flatten + byte-match recompile
node submit-verify-5.mjs SwapLoop   # POST flattened-code → scan.bohr.life

Flatten output lives in agent-vault/verify5/*.flat.sol. Each flat was recompiled and byte-matched against the deployed runtime before submission (FLAT MATCH ×7).

SwapLoop is a testnet deployment. Test tokens have no monetary value.
